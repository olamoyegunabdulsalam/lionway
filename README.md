# Lion-Way Ventures

**Solar Solutions for Homes & Streets in Nigeria.**

A premium, editorial-style marketing website for Lion-Way Ventures — a Nigerian solar company providing installation, sales and maintenance for homes, businesses and streets.

Built with React, Tailwind CSS v4, Framer Motion and Vite. Light mode by default, dark mode supported.

---

## About the brand

**Lion-Way Ventures** provides solar solutions for homes, businesses and streets across Nigeria.

- **Based in:** Lagos, Nigeria
- **Delivery:** Nationwide
- **Services:** Installation · Sales · Maintenance
- **Products:** Solar panels · Inverters · Solar street lights
- **Primary CTA:** Get a Quote

The website intentionally avoids the look of a typical Nigerian business site, a generic solar template, or a SaaS landing page. It's designed to feel like an **architecture or engineering studio** — editorial layouts, large typography, asymmetric grids, restrained motion, and a recurring **sun motif** that anchors the whole visual system.



## Tech stack

| Layer | Choice | Why |
|---|---|---|
| Framework | React 18 | Component model, ecosystem |
| Build tool | Vite 5 | Fast dev server, native ESM |
| Styling | Tailwind CSS v4 | CSS-first config via `@theme`, no `tailwind.config.js` needed |
| Animation | Framer Motion | `whileInView`, `useScroll`, `AnimatePresence`, layout animations |
| Icons | Lucide React | Lightweight, consistent stroke weight |
| Fonts | Manrope (Google Fonts) | Wide weight range, editorial feel |

No additional UI libraries, no CSS-in-JS, no state management library. State is local React state + one theme context.
